<objective>
Entregar a fatia vertical central da fase: a taxa da imobiliária passa a aparecer na mesma lista
cronológica do histórico da parcela, com rótulo de origem e botão "Cancelar" próprio — e cancelar o
pagamento que gerou aquela taxa passa a removê-la junto, automaticamente, via cascata de banco (nenhum
código novo em `cancelarLancamentoAction`).

Este plano prova, com escrita e leitura reais em produção, que a fronteira estrutural de D-04
(13-CONTEXT.md) sobrevive intacta mesmo depois de a taxa ganhar visibilidade e um mecanismo de
cancelamento próprio: nenhuma leitura de `taxas_imobiliaria` participa do cálculo de `valorDevido`/
`valorPago`/`status`, e cancelar uma taxa nunca aciona `recalcularEGravarStatus`.

Purpose: CANIMOB-01, CANIMOB-02, CANIMOB-03 (a parte de aplicação — a coluna e a cascata já existem desde
o plano 14-03) e CANIMOB-05 (parte taxa) — o gestor vê a taxa junto do pagamento que a gerou e consegue
desfazer as duas coisas, juntas ou separadamente.
Output: `ParcelaHistoricoSheet` mostrando o histórico unificado, `CancelarLancamentoDialog` generalizado,
`cancelarTaxaImobiliariaAction` nova, `registrarPagamentoAction` gravando `lancamento_id`, e a prova em
produção de que cancelar um pagamento remove a taxa vinculada.
</objective>

export async function cancelarTaxaImobiliariaAction(
  parcelaId: string,
  taxaId: string
): Promise<ActionResult> {
  const sessao = await requireUser()
  if (!sessao) return { ok: false, error: NAO_AUTENTICADO }

  const invalido = id(parcelaId, "Parcela") ?? id(taxaId, "Taxa")
  if (invalido) return { ok: false, error: invalido }

  const recusaConciliada = await exigirParcelaNaoConciliada(sessao.supabase, parcelaId)
  if (recusaConciliada) return { ok: false, error: recusaConciliada }

  const { data, error } = await sessao.supabase
    .from("taxas_imobiliaria")
    .delete()
    .eq("id", taxaId)
    .eq("parcela_id", parcelaId)
    .select("id")

  if (error) {
    console.error("cancelarTaxaImobiliaria", error)
    return { ok: false, error: erroDoBanco(error.code, "cancelar a taxa") }
  }
  if (!data || data.length === 0) {
    return { ok: false, error: semLinhas("cancelar a taxa") }
  }

  return { ok: true, data: undefined }
}
