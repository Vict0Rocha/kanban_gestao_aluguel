<objective>
Ligar a primeira das duas últimas ações do livro-razão financeiro: conciliar uma parcela paga, em um clique, ponta a ponta — botão na tabela, Server Action, UPDATE condicionado no banco — e travar no servidor a escrita em qualquer parcela já conciliada, para que baixa/ajuste parem de aceitar lançamento numa parcela travada mesmo que a tela de quem chamar esteja desatualizada.

Este é o slice mais fino que atravessa toda a camada que a fase toca (Server Action -> bridge -> UI): Conciliar não tem diálogo (D-07), então é o caminho mais curto possível para provar a arquitetura ponta a ponta antes de expandir para Destravar (plano 07-02), que tem diálogo e histórico.

Purpose: CONCIL-01 (conciliar trava a parcela) e CONCIL-02 (a trava de escrita, no servidor, não só escondendo botão).
Output: `conciliarParcelaAction`/`conciliarParcela`, o botão Conciliar na linha de uma parcela paga, o toast de falha dedicado, e a recusa server-side de pagamento/ajuste sobre parcela conciliada.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| navegador -> Server Action | O botão Conciliar e os diálogos de Pagamento/Ajustar são conveniência; a trava real vive nas Server Actions, reconsultando o banco |
