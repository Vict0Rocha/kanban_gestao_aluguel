símbolos:

1. `usePagination<T>(itens: T[], resetKey: unknown)` — hook genérico que devolve `{ itensDaPagina, pagina,
   totalPaginas, setPagina }`. Tamanho de página fixo em uma constante `TAMANHO_PAGINA = 10` (D-05,
   15-CONTEXT.md — número fixo, não configurável pelo usuário final). O reset de página acontece durante a
   renderização comparando `resetKey` contra o valor guardado da última renderização (`if (resetKey !==
   ultimaChave) { setUltimaChave(resetKey); setPagina(1) }`) — nunca dentro de um `useEffect`, porque isso
   dispararia a cada `router.refresh()` mesmo sem o filtro ter mudado (Pitfall 3, 15-RESEARCH.md).
   `paginaEfetiva` usa `Math.min(pagina, totalPaginas)` para nunca ficar numa página vazia se a lista
   encolher. Copiar a implementação completa de RESEARCH.md Pattern 4 — não redesenhar a lógica de zero.

2. `Pagination({ pagina, totalPaginas, onPaginaChange })` — componente visual. Navegação numerada (1, 2,
   3… + setas anterior/próxima usando `ChevronLeft`/`ChevronRight` de `lucide-react`), usando `Button` de
   `@/components/ui/button` (mesmo padrão de `search-field.tsx` usando `Input`). Retorna `null` quando
   `totalPaginas <= 1` (nada a paginar). Botão da página atual usa `variant="default"` e `aria-current="page"`;
   os demais usam `variant="ghost"`. Sem lógica de elipse/truncamento — no volume atual do projeto
   (~46-48 registros / 10 por página ≈ 5 páginas), uma lista simples de botões numerados cobre o caso real
   (Nota sobre breakpoints mobile, 15-RESEARCH.md Pattern 4).
