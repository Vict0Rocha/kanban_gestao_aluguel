## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| SearchField (`<Input>` do usuário) → filtro em memória | o termo digitado nunca sai do navegador — nunca vira parte de uma query SQL, nunca é enviado ao servidor; renderizado só via JSX padrão do React (`value={query}`), auto-escapado |
| `ConfiguracaoFinanceiraPage` (Server Component, inalterado) → `ConfiguracaoFinanceiraView` (Client Component) | a prop `linhas` cruza essa fronteira exatamente como antes desta fase — mesma query, sem filtro de visibilidade novo (A-02), sem campo novo |
| `linhasFiltradas` (subconjunto client-side de `linhas`) | o filtro só pode ESCONDER linhas do conjunto que a RLS (`is_team_member()`) já autorizou para esta sessão — nunca revela nada que o usuário não pudesse já ver antes desta fase |
